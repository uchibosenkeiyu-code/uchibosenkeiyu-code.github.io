お薬リマインダー

公式サポート・よくある質問
更新日：2026年10月19日

薬の名前・毎日の時刻・知らせ方を一度設定したら、あとはお知らせを受け取るだけ。毎日のアプリ起動や服用記録を求めない、iPhone向けのリマインダーです。

iOS 17以降に対応。「通知だけ（音なし）」を使えます。「アラーム」はiOS 26以降で利用できます。

使い始めるには

  1. ホームの「＋ お薬を追加」をタップします。
  2. 薬の名前を入力し、時刻の候補を選ぶか、「時刻を入力」で数字を入力します。
  3. 「通知だけ（音なし）」または「アラーム」を選び、「保存」をタップします。初期選択は音なしです。
  4. 許可の確認が表示された場合は、選んだ知らせ方に必要な許可を確認してください。

よくある質問

複数の薬や、1日複数回の時刻を登録できますか？
はい。薬はホームから追加できます。1つの薬の時刻は「＋ 時刻を追加」で増やせます。時刻は毎日繰り返します。
時刻を数字で入力できますか？
「時刻を入力」、または設定済みの時刻をタップすると数字のキーボードが表示されます。例えば「0830」で「08:30」を入力できます。入力後は「完了」をタップしてから薬を保存してください。
保存せずに閉じたらどうなりますか？
×で閉じた内容は保存されません。追加画面は下にスワイプして閉じることもできます。保存前の変更は、保存済みの薬や予約へ反映されません。保存に失敗した場合は入力内容を残してエラーを表示するので、内容を確認してください。
毎日アプリを開く必要がありますか？
保存した通知・アラームの繰り返しはiPhoneのOSに予約します。毎日アプリを開いたり、服用済みを記録したりする必要はありません。
お知らせが届きません。
薬を開いて保存済みの時刻と知らせ方を確認してください。「通知だけ」は音が鳴りません。iPhoneの設定で本アプリの通知が許可されているか、通知の表示先や集中モードの設定を確認してください。「アラーム」はiOS 26以降とアラームの許可が必要です。保存画面に「設定を開く」が表示された場合は、そこから許可を確認できます。
薬や時刻の変更・削除はどうしますか？
ホームの薬をタップすると編集できます。変更は「保存」で反映されます。「この薬を削除」から削除すると、その薬のデータと対応する予約を解除します。同じ時刻に別の薬が登録されている場合、その薬のお知らせは残ります。
無料ですか？広告が表示されないと使えませんか？
無料で利用できます。ホーム内の小さなバナー広告1枠で運営し、アプリ内課金・定期購読・登録数による機能制限はありません。全画面広告や広告視聴の要求はありません。通信なし・広告未配信・読み込み失敗でも、薬の登録・保存・通知・アラームは利用できます。
登録した薬の情報は送信されますか？
薬名・時刻・知らせ方は端末内で扱い、開発者のサーバーや広告SDKへ送信しません。一方、広告SDKはIPアドレスや広告表示・操作情報などを扱う場合があります。詳しくはプライバシーポリシーをご覧ください。

お問い合わせ・広告の報告

不具合、ご意見、プライバシーに関するご質問、不適切な広告の報告は、次の窓口へお送りください。

GitHub Issuesでお問い合わせ

GitHubアカウントが必要です。投稿内容は公開されます。薬名・服用時刻・病名などの健康情報や、氏名・メールアドレスは記載しないでください。添付画像にも含めないでください。

iPhoneの機種、iOSとアプリのバージョン、起きたこと、操作手順をお知らせください。広告の報告は広告の表示日時や内容が分かると確認に役立ちます。任意に投稿いただく情報の扱いは、こちらに記載しています。
