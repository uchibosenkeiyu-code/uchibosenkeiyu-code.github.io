プライバシーポリシー

最終改訂日：2026年10月17日 | 適用開始日：2026年10月17日 | 開発者：uchibosenkeiyu

本プライバシーポリシーは、uchibosenkeiyu（以下「当方」）が提供するiOS向けアプリケーション『SNS依存脱却』（以下「本アプリ」）における利用者情報の取扱いについて定めたものです。

基本方針：
本アプリは、利用者のプライバシー保護を最重要事項として設計されています。Appleの提供する「Screen Time（Family Controls / DeviceActivity）」フレームワークを利用してSNSアプリの利用時間を可視化・目標管理しますが、利用者の実利用時間、選択したアプリ名、目標設定、依存度判定、獲得した称号等の個人データを、外部サーバーやクラウド、広告ネットワークへ送信・収集することは一切ありません。

1. 取得する情報とその取扱い

1.1 スクリーンタイム・アプリ利用時間データ

  • 対象データ：利用者が本アプリ内で選択したSNSアプリ・カテゴリの利用時間、日別利用推移、内訳データ。
  • 処理の場所：すべて利用者の端末内（iOSが管理する DeviceActivityReportExtension の独立サンドボックス内）でのみ処理・表示されます。
  • 外部送信の有無：一切送信しません。 本データは当方のサーバー、第三者の分析ツール、広告配信事業者へ送信されることは技術的に完全に遮断されています。
  • ホストアプリとの境界：利用時間・アプリ名はホストアプリ本体やApp Groupコンテナへも書き出されず、レポート拡張機能（SNSDetoxReport.appex）の内部でのみ描画されます。

1.2 目標設定およびアプリ内設定データ

  • 対象データ：1日の目標利用時間、計測対象アプリの選択有無フラグ、選択バージョン識別子（ハッシュ値）、外観テーマ設定（ライト／ダーク／端末連動）、共有時の内訳表示トグル。
  • 保管場所：利用者の端末内（App Group group.com.uchibosenkeiyu.SNSDetox 共有コンテナ）にのみ保存されます。
  • 外部送信の有無：一切送信しません。

1.3 広告配信に伴う情報収集（Google AdMob SDK）

本アプリは、開発・運営費用の維持のため、無料提供の一環としてGoogle AdMobによる広告を掲載しています（分析画面の「取り組み」タブ最下部にバナー広告1枠のみ）。

  • 収集事業者：Google LLC およびその関係会社
  • 同梱SDKバージョン：Google Mobile Ads SDK 11.13.0 / Google User Messaging Platform (UMP) SDK 2.7.0
  • 収集される可能性のある情報（Google SDK仕様およびプライバシーマニフェスト準拠）：
    • 識別子：端末ID（Device ID / ベンダー識別子等）
    • 使用状況データ：製品の操作（広告の閲覧・タップ等）、広告データ（インプレッション測定等）
    • 位置情報：おおよその位置情報（Coarse Location: IPアドレス等から推定される地域情報）
    • 診断情報：クラッシュデータ、パフォーマンスデータ、その他の診断データ
  • 利用データの非提供：本アプリのスクリーンタイムデータ、利用時間、アプリ選択、依存度、称号情報は、Google AdMobを含むいかなる広告事業者にも提供されません。
  • 同意管理：欧州経済領域（EEA）や英国等の該当地域において、Google User Messaging Platform（UMP）SDKを通じた同意管理を提供し、利用者のプライバシー設定を尊重します。

2. 情報の第三者提供・共同利用

当方は、以下の場合を除き、利用者の情報を第三者へ開示・提供・販売することはありません。

  1. 法令に基づく開示要請があった場合
  2. 人の生命、身体または財産の保護のために必要がある場合
